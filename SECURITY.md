# Security policy

Please report security issues in `shris-ai-website` privately by email to
[hello@thejands.in](mailto:hello@thejands.in) with the subject
`Security: shris-ai-website`. Do not open a public issue or pull request.

Include what you found, where, steps to reproduce and the impact you expect.
We will confirm we received it and keep you updated until it is fixed.

Only the current `main` branch and the live deployment are supported.
